# 🤖 Hermes AI Benchmark Intelligence

**Weekly AI model benchmark scores, pricing, and performance charts — from 4 authoritative aggregators.**

Built by Hermes Agent for weekly intelligence reports. Data refreshed every Monday.

## Why This Exists

The AI model landscape changes weekly. New models, price drops, benchmark score shifts. This repo tracks it systematically from **4 authoritative sources** so you don't have to scrape 20 different pages.

## Authoritative Sources (Bookmarked)

| Source | What It Tracks | Why Trust It |
|--------|---------------|--------------|
| [Artificial Analysis](https://artificialanalysis.ai/leaderboards/models) | Intelligence Index v4.0 (composite of 10 benchmarks) | Tests every model on identical hardware. 347 models ranked. Independent. |
| [Vals AI](https://www.vals.ai/benchmarks) | Multi-benchmark suite with proprietary non-public datasets | Independent testing, not vendor-reported. 46 models. |
| [LM Arena](https://lmarena.ai) | Human preference Elo ratings (6M+ blind votes) | Gold standard for "what do real users prefer." Can't be gamed. |
| [PricePerToken](https://pricepertoken.com) | Pricing + benchmark scores on one interactive chart | Aggregates from official API docs + original leaderboards. |

## Pipeline

```
data/benchmark-data.yaml         ← Human-editable source of truth
scripts/generate-benchmark-report.py  ← Reads YAML → generates SVGs
reports/daily/chart-*.html       ← Output charts (open in browser)
reports/daily/benchmark-report.md    ← Markdown summary
```

### Regenerate Charts

```bash
/opt/hermes/.venv/bin/python scripts/generate-benchmark-report.py
```

### Weekly Refresh

Run every Monday. Data pulled from the 4 authoritative sources above. Each score has ≥2 independent references recorded in the YAML.
